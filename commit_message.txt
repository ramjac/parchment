Add document editor left outline pane (PR 18)

This change implements a left-side navigation outline pane in the document editor.
It adds a toggle keybinding (`Ctrl+O`) that opens an outline pane tracking
headings in the document. `F6` shifts focus to the outline pane. When the
outline pane is visible and focused, users can navigate it via up/down and jump
to sections using Enter, or mouse clicks.

Additionally, `Tab` is now freed to insert 2 spaces into the document body,
while returning to the editor body from other focused states.
